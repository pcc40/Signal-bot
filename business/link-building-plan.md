Research and writing only: **nothing in this file has been submitted, sent or published, and the website has not been changed.** It adds to `business/authority-profiles.md` (profiles already planned or done) and `business/offsite-authority-kit.md`; where they overlap, this file says so instead of repeating them.

**Why this matters.** Search Console and Bing both show 0 external links to eastbridgestrategicpartners.com (STATUS.md, 12 Nov). The site has 95 pages, 29 articles and 4 tools, and is indexed (452 pages), with average position around 22. That is the "foundation gap" pattern: good pages, no third-party votes. The order of work below follows that: partners and honest listings first, then expert quotes and guest articles, then paid memberships only where they also bring referrers.

**Rules for every item** (from `.agents/product-marketing.md` and the link-building skill)
- Never pay for a link that passes ranking credit, never use link packages, private blog networks or "niche edits". A paid listing is fine only as a listing, not as a link purchase.
- Reciprocal links only with relevant firms Phil would genuinely refer to, and only a handful. No link-swap pages.
- Let the other site choose the anchor text. Our brand name or plain URL is ideal.
- Never claim a UAE project, client or UAE experience; never mention team size, team names or turnover; never use supervise, certify, turnkey, "on your behalf", obtain or submit permits, prequalify, or engineer as a verb. British English, no exclamation marks.
- **Use copy A and copy B from `authority-profiles.md` section 1, not copy C or D.** Copies C and D say "supported by three project managers", which is team-size detail the hard rules now forbid. Fix C and D before reusing them anywhere (flagged, not changed).
- Every new profile URL goes into the tracker in `authority-profiles.md` section 9 and, once live, into `SOCIAL` in `src/config.py` (done by a site session, not by this plan).

**Link attribute note.** Whether a directory's website link is followed or nofollow is rarely documented and changes often. Where this file says "unverified", check the live profile with the browser's inspect tool and record it. Treat directories as entity consistency and AI-citation surface; the followed links that move rankings will mostly come from sections 2 to 4.
